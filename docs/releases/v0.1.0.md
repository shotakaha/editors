# v0.1.0 - First release: Vim, Emacs and Zed configurations

## What Changed?

This is the first release of the editors configurations.
It provides ready-to-install configuration files for Vim, Emacs and Zed, all using Emacs-like keybinds and XDG paths where the editor supports them.
Task commands install the files and keep a backup of the existing ones.

---

## What's New

### Vim

**What it does**:
A vimrc with [vim-plug](https://github.com/junegunn/vim-plug), Emacs-like keybinds (`C-f`, `C-b`, `C-k`, `C-y`, `C-x C-s`, `C-x 2`, ...) and Vim features kept under the leader key (`SPC`).
It has two versions:

| File | Target |
| --- | --- |
| `vim9/vimrc` | Vim 9.1.0327 or later (XDG compliant, `<Cmd>` mappings) |
| `vim8/vimrc` | Vim 8.0 or later (`~/.vimrc`) |

**How to use it**:
Install `vim9/vimrc` to `~/.config/vim/vimrc`, or `vim8/vimrc` to `~/.vimrc`.
vim-plug and the plugins (editorconfig-vim, vim-airline, vim-commentary) are installed on the first run.

### Emacs

**What it does**:
An `init.el` and `early-init.el` with a minimal completion UI (Vertico, Orderless, Consult, Marginalia, Corfu, Cape), Magit and Doom Modeline.
It has two versions:

| Directory | Target |
| --- | --- |
| `emacs31/` | Emacs 31 (package.el and the built-in use-package) |
| `emacs28/` | Emacs 28 or later (use-package installed with straight.el) |

**How to use it**:
Install the files to `~/.config/emacs/`.
Run `M-x nerd-icons-install-fonts` once to install the icon fonts.

### Zed

**What it does**:
A `settings.json` and `keymap.json` with the Emacs base keymap, a theme that follows the system appearance, and fish as the terminal shell.

**How to use it**:
Install the files to `~/.config/zed/`.

### Task commands

**What it does**:
`task install:vim9`, `task install:emacs31` and `task install:zed` install the files to the XDG paths.
The existing files are saved as `<file>.bak`.
`install:vim9` and `install:emacs31` stop if a legacy file (`~/.vimrc`, `~/.vim/vimrc`, `~/.emacs`, `~/.emacs.d`) exists, because it takes precedence over the XDG path.

**Code example**:

```sh
task install:vim9
task install:emacs31
task install:zed
```

## Installation

### Quick Start

```sh
# Get the release
git clone https://github.com/shotakaha/editors.git
cd editors
git checkout 0.1.0

# Install (XDG paths)
task install:vim9
task install:emacs31
task install:zed
```

Without Task, use the `curl` steps in the [README](https://github.com/shotakaha/editors#readme).
They also cover `vim8/vimrc`, `emacs28/` and the fish shell.

## Is It Safe to Upgrade?

**Backward Compatible**: Not applicable (first release)

- The install tasks save the existing files as `<file>.bak` before replacing them.
- The XDG paths are not read if a legacy file such as `~/.vimrc` or `~/.emacs.d` exists. Move it away first.

## Verification

- `vim9/vimrc` and `vim8/vimrc` load without errors in Vim 9.1 (headless).
- `vim8/vimrc` starts normally in Vim 8.0 on a real machine.
- `emacs31/` and `emacs28/` load, and install their packages, in Emacs 31.1 (batch mode).
- `task install:*` installs the files to a temporary `$HOME`, and keeps backups.

Not verified: `emacs28/` on Emacs 28 or 29, and interactive use of Magit and the Emacs-like keybinds.
